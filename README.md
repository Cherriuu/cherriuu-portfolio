# Jesica Portfolio

A Vite + React portfolio matching the pink/snowy mockup.

## Run it

```bash
npm install
npm run dev
```

## Customize

- Replace `youremail@example.com` in `src/App.jsx`
- Replace the LinkedIn `href="#"` with your profile URL
- Replace each project `href: "#"` with the correct GitHub/live link
- Put your resume at `public/resume.pdf` if you want the Resume link to work
- To use a real profile photo, replace `.portrait-placeholder` with an `<img>` in `App.jsx`

The falling snow is pure CSS/React and respects `prefers-reduced-motion`.
